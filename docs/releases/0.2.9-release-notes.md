# PlayBridge 0.2.9 — experimental Android APK

Binary distribution of the user-supplied PlayBridge prototype. This repository contains the product website; its source archives are **not** the Android app source code.

## Download requirements

- Android 12 or later (minimum SDK 31, as declared by the APK).
- ARM64 (`arm64-v8a`) device; no other native ABI is included.
- Version: 0.2.9; version code: 20; package: `com.playbridge.app`.
- APK size: 382,236 bytes (373.3 KiB).

Download `PlayBridge-0.2.9-arm64-release.apk` to your Android phone and open it. Android may ask you to allow installations from the browser or file manager used to open it. Set up and test only while safely parked.
